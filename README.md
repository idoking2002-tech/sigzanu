# SIGAZNU

ערב משחקי חברה בעברית לטלפון. המארח פותח חדר, החברים נכנסים עם קוד של 4 אותיות, וכל טלפון מקבל רק את מה שהשחקן שלו צריך לראות.

## הרצה מקומית

```bash
npm install
npm start
```

ואז לפתוח http://localhost:3000. כדי לשחק מכמה טלפונים באותה רשת, פותחים בטלפון את כתובת ה־IP של המחשב, למשל `http://192.168.1.20:3000`.

## מבנה

| קובץ | מה יש בו |
| --- | --- |
| `server.js` | שרת HTTP ו־WebSocket, חדרים, שחקנים, ניקוד הערב |
| `games.js` | הלוגיקה של כל 13 המשחקים. כל משחק מחזיר "מסך" לכל שחקן |
| `content.js` | מילים, קטגוריות, עובדות, אתגרים. אפשר להוסיף חופשי |
| `public/index.html` | האתר: דף הבית, פתיחת חדר, הצטרפות, ותצוגת המשחקים |

החדרים נשמרים בזיכרון, ולכן צריך להריץ מופע אחד בלבד של השרת. הפעלה מחדש של השרת סוגרת את החדרים הפתוחים.

## העלאה לאוויר בחינם (Render)

הכתובת תהיה **https://sigaznu.onrender.com** — בחינם, עם HTTPS, בלי לקנות דומיין.

1. פותחים חשבון חינמי ב־GitHub ומעלים את התיקייה הזו לריפו חדש (Add file → Upload files, בלי `node_modules`).
2. פותחים חשבון חינמי ב־Render ומחברים את GitHub.
3. New → Blueprint, בוחרים את הריפו. הקובץ `render.yaml` כבר קורא לשירות `sigaznu`, ולכן הכתובת תהיה `sigaznu.onrender.com`. אם Render מציג שם עם תוספת (למשל `sigaznu-x1y2`), השם נתפס בינתיים.
4. בוחרים בתוכנית Free ומחכים שהבנייה תסתיים.

קישורי חדרים נבנים אוטומטית מהכתובת, למשל `https://sigaznu.onrender.com/ABCD`.

אם בעתיד תרצו דומיין משלכם: Settings → Custom Domains ב־Render, ומגדירים את רשומות ה־DNS שהוא מציג אצל רשם הדומיין.

בתוכנית החינמית של Render השרת נרדם אחרי זמן בלי שימוש, וההתעוררות לוקחת כמה עשרות שניות. לערבי משחקים אמיתיים עדיף תוכנית בתשלום שלא נרדמת.

אפשר גם להריץ עם Docker בכל שרת: `docker build -t sigaznu . && docker run -p 3000:3000 sigaznu`.
